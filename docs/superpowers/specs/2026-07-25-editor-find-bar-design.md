# 编辑器查找框设计

## 目标

为 Markdown 编辑器提供紧凑的正文内查找框。查找框应明确归属于当前编辑区域，
不能以整个应用窗口为定位参照。

## 位置与归属

- 查找框悬浮在当前正文编辑区域的右上角，不占用正文布局高度。
- 查找框的定位容器是对应的编辑面板；侧栏宽度和应用窗口宽度变化时，查找框仍贴合
  正文区域右上角。
- 双栏模式下，查找框显示在当前获得焦点的正文栏内部。
- 从左栏切换到右栏或从右栏切换到左栏时，查找框随当前查找目标移动。
- 关闭右栏时，如果查找目标属于右栏，应关闭查找框并恢复左栏为活动编辑器。

## 控件

查找框从左到右依次包含：

1. 查找输入框。
2. 当前命中数与总命中数，例如 `1 / 4`。
3. `↑` 按钮，跳转到上一个命中。
4. `↓` 按钮，跳转到下一个命中。
5. `×` 按钮，关闭查找框。

按钮同时保留中文无障碍标签和提示文字：“上一个”“下一个”“关闭”。

## 交互

- `Command+F` 或 `Ctrl+F` 在当前活动编辑器中打开查找框。
- 输入内容后即时更新命中结果。
- `Enter` 跳转到下一个命中，`Shift+Enter` 跳转到上一个命中。
- 点击 `↑` 和 `↓` 循环切换命中。
- `Escape` 或点击 `×` 关闭查找框，并将焦点返回原编辑器。
- 普通命中与当前命中使用不同的高亮样式。

## 视觉

- 使用紧凑的桌面编辑器浮层样式，弱化圆角和阴影。
- 查找框与正文区域顶部、右侧保留一致的小间距。
- `↑`、`↓` 使用方向明确的箭头图标，不使用折线或含义模糊的符号。
- 深色和浅色主题下均保持边界、文字和焦点状态清晰。

## 验证

- 检查单栏和双栏模式下，查找框均位于对应正文区域右上角。
- 调整侧栏宽度和窗口尺寸，确认查找框不会按整个窗口错误定位。
- 验证 `↑`、`↓`、`Enter`、`Shift+Enter` 和循环导航行为。
- 验证关闭右栏、切换笔记库、进入阅读模式时能正确清理查找状态。
- 验证键盘焦点样式及中文无障碍标签。
