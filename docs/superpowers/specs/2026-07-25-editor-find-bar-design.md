# 编辑器查找框设计

## 目标

为 Markdown 编辑器提供紧凑的正文内查找框。查找框应明确归属于当前编辑面板，
在顶部独占一行且不遮挡正文。

## 位置与归属

- 查找框位于当前编辑面板的标题行下方、正文容器上方，作为独立布局行参与排版。
- 查找框打开时正文整体下移，不覆盖编辑器或预览内容；关闭时整行隐藏并释放高度。
- 查找框横向撑满所属编辑面板，不使用绝对定位。
- 双栏模式下，查找框显示在当前获得焦点的编辑面板内，并撑满该面板宽度。
- 从左栏切换到右栏或从右栏切换到左栏时，查找框随当前查找目标移动。
- 关闭右栏时，如果查找目标属于右栏，应关闭查找框并恢复左栏为活动编辑器。

## 控件

查找框从左到右依次包含：

1. 查找输入框。
2. 当前命中数与总命中数，例如 `1 / 4`。
3. `↑` 按钮，跳转到上一个命中。
4. `↓` 按钮，跳转到下一个命中。
5. `×` 按钮，关闭查找框。

按钮同时保留中文无障碍标签和提示文字：“上一个”“下一个”“关闭”。

## 交互

- `Command+F` 或 `Ctrl+F` 在当前活动编辑器中打开查找框。
- 输入内容后即时更新命中结果。
- `Enter` 跳转到下一个命中，`Shift+Enter` 跳转到上一个命中。
- 点击 `↑` 和 `↓` 循环切换命中。
- `Escape` 或点击 `×` 关闭查找框，并将焦点返回原编辑器。
- 普通命中与当前命中使用不同的高亮样式。

## 视觉

- 保留现有查找框的颜色、边框、圆角、阴影、图标、按钮与焦点样式。
- 外框宽度为所属编辑面板的完整可用宽度。
- 查找输入框使用弹性宽度，填满计数器和操作按钮以外的全部空白区域。
- `↑`、`↓` 使用方向明确的箭头图标，不使用折线或含义模糊的符号。
- 深色和浅色主题下均保持边界、文字和焦点状态清晰。

## 验证

- 检查单栏和双栏模式下，查找框均位于对应标题与正文之间并独占一行。
- 调整侧栏宽度和窗口尺寸，确认外框始终撑满所属面板，输入框填满剩余空间。
- 确认查找框打开时正文下移且没有内容被遮挡，关闭后不残留空白行。
- 验证 `↑`、`↓`、`Enter`、`Shift+Enter` 和循环导航行为。
- 验证关闭右栏、切换笔记库、进入阅读模式时能正确清理查找状态。
- 验证键盘焦点样式及中文无障碍标签。
